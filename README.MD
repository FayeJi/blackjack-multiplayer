This is a blackjack web online game supporting multiplayer in real time, players are able to join game room and start play with dealers and other players in the same room.

The project is set up using Java Spring Boot, Spring Security, Angular, MySQL and Gradle

You need to download MySQL server and set up connection in application.properties file, start MySQL server, when the application start it will create tables automatically for you

CLONE PROJECT, from intellij add gradle file and refresh dependency build project with gradle 21, 

Run the main method in BlackjackApplication.java, no arguments needed

on angular terminal, run ng serve
